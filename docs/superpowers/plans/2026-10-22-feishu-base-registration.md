# 飞书多维表格登记实施计划

**Goal:** 把应用和部署任务安全、可靠地镜像到新建的飞书 Base。

**Architecture:** 独立进程扫描 SQLite 的安全投影并写入持久化同步账本，再按版本写入 Base；本地状态权威。飞书失败时重试，不影响部署。

**Tech Stack:** Python 3.13、SQLite、FastAPI、httpx、飞书 Base OpenAPI、systemd。

1. 在指定文件夹用用户身份新建 Base 和两张表，核对字段与 ID；将平台飞书应用加入该 Base 为编辑协作者，仅授必要 API 权限。
2. 新增独立配置校验，提供 Base token、应用表 ID、部署表 ID；未启动同步服务时功能关闭。
3. 新增独立同步模块：安全投影、待同步账本、远端查找/创建/更新、指数退避和状态查询；通过扫描变更应用和部署任务，旧数据自动回填。
4. 新增 `base-sync --once` 与 systemd service；首次上线只启用同步服务，不改变业务 worker 的运行路径。
5. 用 MockTransport 和临时 SQLite 验证重复运行不重行、故障后重试、不泄露秘密、并发状态不丢失、下线状态更新；执行相关回归测试。
6. 发布至目标服务器，配置新 Base；在不触碰业务容器的前提下真实回填并核对行数及字段，检查待办清零和错误状态。
