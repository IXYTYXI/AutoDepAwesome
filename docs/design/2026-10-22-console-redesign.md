# Awesome Deploy 控制台视觉系统

目标是让桌面端部署操作呈现为清晰、可信的管理工具。保留现有信息架构、表单字段、权限和业务行为，统一重做六个页面及其动态状态。

视觉方向采用 UI/UX Pro Max 检索到的 Minimalism & Swiss Style：留白、明确的排版层级、少量高对比色和细边框。深海军蓝用于导航与品牌，蓝色只用于主要操作和选中态；成功、警告、危险各用独立语义色。内容区为浅灰画布与白色工作面板，不采用渐变或大面积发光效果。

字体使用系统中文无衬线与本机等宽字体。正文至少 14px，关键说明 15–16px；按钮和输入框最小高度 44px。页标题、面板标题、字段标签、帮助文字形成四级层级。数值及编号使用等宽或等宽数字。间距采用 4/8/12/16/24/32 的序列，边角统一为 6–10px。

页面结构：所有登录后页面共享深色顶部导航、标题区和白色工作面板。部署页保持左表单、右进度与下方历史的任务流；应用管理页保持概况、在线应用、队列及已下线记录；API 凭证页保持创建和列表并列；使用手册保持左目录右正文；成员与密钥对话框复用同一控件语言。登录页采用品牌说明与登录面板的双栏构图。

交互状态必须覆盖默认、悬停、键盘焦点、选中、禁用、加载、空态、错误、危险确认和长文本。已有列表滚动边界保留，文档正文独立滚动。响应式只保证窄窗口可操作，不增加独立手机版功能。

实现采用一个在现有页面样式之后加载的共享主题层。这样可统一替换视觉系统，同时保留经过验证的表单与业务交互；旧 CSS 的功能布局规则继续生效。验收以实际浏览器操作、界面截图、现有测试和 CSS/HTML 静态审查为准。
