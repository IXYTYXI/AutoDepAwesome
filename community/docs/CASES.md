# AI 案例库

来源：同一 Base 的 `tbldtSGzcfa6twD0`，指定视图 `vew4BiClvU`。当前视图没有显式 sort，后端不附加 sort/filter，按飞书返回顺序分页拼接；前端不按日期、标题或分类重新排序。首页从可展示集合取前三条，案例库按同一集合筛选并每页展示 6 条。

## 请求及缓存

浏览器仅通过已登录同源请求 `GET /api/v1/cases` 获取案例。接口默认鉴权，并可配置来源租户校验。应用身份查询飞书，不依赖 lark-cli 的用户会话。首页、案例库、详情、SkillHub 共用这一份数据源快照，不按用户生成副本。

Redis 键：`<prefix>:cases:v3:<sha256(app_id|base|table|view)前24位>:<suffix>`。

- `fresh`：1800 秒（30 分钟），普通读取不续期。
- `snapshot`：604800 秒（7 天），每次成功刷新重新计算。
- `lock`：60 秒；刷新总超时 45 秒，并发等待者最多等待 10 秒，有旧快照则返回 `stale=true`。
- `cooldown`：刷新失败后 15 秒内不再回源。
- 刷新完成通过 Redis 事务同时更新快照和新鲜标记，防止半成品发布。
- Redis 不可用返回统一 503，不绕开 Redis 向飞书发请求；无旧数据时失败返回统一错误，不使用演示案例冒充真实结果。

这是请求触发更新，不是后台定时推送。飞书改动通常在新鲜期到期后的下一次访问生效；已经打开的页面需重新加载。重试按钮会重新请求后端，仍遵守后端缓存，不允许客户端强制回源。

## 字段和展示

映射作品名、一句话描述、所属团队、第一作者、作品tag、产物类型、案例来源、案例编号、敏感风控、文档 / 链接、封面附件。排除作者邮箱等不需要的字段。

用户确认的展示策略：只排除 `暂不公开`；其余案例展示元信息、安全的 HTTP(S) 原链接和联系作者入口。`需申请权限` 保留访问提示，目标系统独立校验实际使用权限。缺失整个敏感风控字段时视为源权限/结构异常，不发布不完整快照。

已支持「封面」附件：后端缓存图片并返回鉴权媒体路径，空图或加载失败时使用 CSS 档案插图。具体缓存、更新、部署与上传步骤见 [CASE_COVERS.md](CASE_COVERS.md)。没有从原链接自动抓取网页内容，描述缺失时留空。

历史本机分享仅在“我的分享”展示，不插到首页前三条或官方案例库。资讯不属于此接口；Banner 使用独立的飞书表与缓存，见 [BANNER.md](BANNER.md)。

```dotenv
OWS_COMMUNITY_CASES_TABLE_ID=tbldtSGzcfa6twD0
OWS_COMMUNITY_CASES_VIEW_ID=vew4BiClvU
OWS_COMMUNITY_CASES_CACHE_SECONDS=1800
OWS_COMMUNITY_CASES_STALE_SECONDS=604800
OWS_COMMUNITY_CASES_SOURCE_TENANT=
```

沿用现有 Redis 地址、前缀、飞书应用和 Base 配置。本地与服务器均使用相对 API 路径；保留 Redis 持久化卷，修改环境配置后重启服务。来源企业限制应填为与其他企业内接口一致的租户。变更可见性策略或不兼容数据结构时升级缓存版本。

### 扩展字段兼容与团队 AI 官

2026-10-26 对比 lark-cli 和应用 OpenAPI 后，确认「一句话描述」为 is_extend=true 的扩展字段，应用查询没有返回其值。在原案例表新增公式「网站案例描述」（fldQGzvqUT），表达式 `[一句话描述] & ""`，供 OpenAPI 读取；无需重复维护描述。读取优先级：一句话描述 → 网站案例描述 → 一句话简单描述。已用真实应用请求验证该公式返回原描述。

「团队 AI 官」是人员查找引用，后端解析 value 中的人员列表，仅输出姓名及经过 open_id 校验的聊天 URL，不向前端返回邮箱、头像地址或原始字段。多名 AI 官分别提供按钮，同一 open_id 去重，没有有效 ID 时不猜测联系人。随案例共享快照缓存 30 分钟。
