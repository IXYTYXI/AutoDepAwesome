# 前后端与缓存检查（2026-10-26）

## 前端

运行入口为 Vite + Vue 3，登录页独立挂载 Vue，业务页使用 Vue Router 懒加载 SFC；Nuxt UI 是组件库，并未使用 Nuxt SSR。各 HTML 仅是挂载入口。业务页面不存在独立原生 JS 渲染或 innerHTML 拼装。

站内链接统一通过 AppLink → RouterLink，替换手写点击拦截和整页跳转；外链保留浏览器行为。表单字段使用响应式状态。移除无使用入口、无法发布到资讯列表的旧本地资讯分支和不必要的案例 Promise 缓存，公共数据的有效期统一由后端管理。

必要的浏览器 API：Canvas/RAF 粒子、ResizeObserver、页面可见性/恢复事件、焦点与滚动、文档标题、文件读取、原生 dialog，以及 OAuth 跨站跳转。监听器与动画由 Vue 生命周期清理；这些不属于绕过 Vue 的业务渲染。

「分享实践」仍是明确标注的本机案例草稿预览，不是后端发布功能。历史 CSS 兼容层仍被当前组件使用，不能因文件名 legacy 就直接删除；本次没有声称整个项目已零冗余。frontend/assets 中的原始设计素材和预览图不是独立运行页面，实际静态资源来自 public 和 Vite dist。

## 后端

FastAPI 路由 → 服务 → 飞书集成 / Redis Store。所有新业务接口默认鉴权，公共入口采用精确方法和路径白名单；内容额外校验配置的来源租户。重复租户检查与快照发布收敛为公共实现。

## 当前运行配置

| 内容 | 新鲜缓存 | 旧快照保留 |
| --- | --- | --- |
| AI 领航团 | 5 分钟 | 7 天 |
| 案例 | 30 分钟 | 7 天 |
| Banner | 24 小时 | 7 天 |
| AI 资讯 | 10 分钟 | 24 小时 |
| FAQ | 10 分钟 | 24 小时 |

公共内容按应用 / Base / 表 / 视图使用共享键，不按用户复制；会话独立缓存 8 小时。命中不会延长内容 TTL。缓存失效后持互斥锁回源，45 秒刷新超时、60 秒锁、失败 15 秒冷却，原子发布快照与图片索引。失败可返回仍在保留期内的旧快照。Redis 故障不静默改为进程内缓存。

资讯任务每 10 分钟增量同步 AIHOT → 飞书，成功后重新读飞书并发布 Redis；其他表为缓存到期后访问触发刷新，并非定时同步。

图片索引在 Redis，WebP 在服务器媒体目录。请求仍鉴权，并确认图片属于当前有效快照，再复用磁盘文件；新增 Banner / 领航团旧图撤下校验，保留案例 / 资讯既有撤图语义。媒体下载按飞书应用共享速率锁，避免各表分别限流叠加。文件写入使用临时文件与原子替换。

浏览器响应当前统一 no-store，确保每次请求经过后端身份校验；Redis 与磁盘缓存减少的是飞书回源，不能把这与浏览器缓存混为一谈。未覆盖：历史 WebP 磁盘自动清理、媒体目录跨服务器共享；多实例部署需共享媒体卷（或将本地磁盘锁改为节点级设计），同步检查点同样需共享持久卷。现有单机本地/服务器部署应持久化 Redis、媒体和同步状态目录。

静态资源可以进一步做“带身份校验的条件请求”，但不应直接给私有图片加公开 CDN 缓存。本次保持身份校验边界。
